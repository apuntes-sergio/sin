# Sistemas Informáticos
## UD01 · Introducción al sistema informático
### DAM · Sergio Rey Martínez

---

## ¿Qué es un sistema informático?

Conjunto de elementos interrelacionados para:

- **Almacenar** información
- **Procesar** información
- **Transmitir** información

> Hardware + Software + Personas

---

## Hardware vs Software

| | Hardware | Software |
|--|----------|----------|
| **Es** | Físico, tangible | Lógico, intangible |
| **Ejemplos** | CPU, RAM, disco | SO, apps, drivers |
| **Sin el otro** | Piezas inertes | Sin donde ejecutarse |

---

## Tipos de sistemas informáticos

- 🖥️ **PC** — uso individual, equilibrio coste/rendimiento
- 🖧 **Servidor** — da servicio en red, fiabilidad máxima
- 🔧 **Sistema embebido** — dentro de otro dispositivo
- 📱 **Dispositivo móvil** — bajo consumo, tamaño reducido

---

## Los componentes están interrelacionados

```
CPU → socket → Placa Base → tipo de RAM
                   ↓
            interfaces SATA / M.2
                   ↓
            Almacenamiento
```

**Elegir uno condiciona al resto**

---

## Capas del software

| Capa | Ejemplos |
|------|----------|
| **Aplicaciones** | IDE, navegador, ofimática |
| **Sistema Operativo** | Windows, Linux, macOS |
| **Firmware** | BIOS / UEFI |
| **Hardware** | CPU, RAM, disco |

---

## ¿Dónde trabajamos nosotros?

Como desarrolladores trabajamos en la **capa de aplicaciones**...

...pero entender las capas inferiores nos permite:

- Escribir código más **eficiente**
- Resolver problemas **inexplicables**
- Elegir la infraestructura **adecuada**

---

## Resumen

- Un sistema informático = hardware + software + personas
- Todos los componentes están **interrelacionados**
- El hardware sin software es inerte, el software sin hardware no existe
- Como DAM trabajamos en aplicaciones, pero necesitamos entender todo el sistema
